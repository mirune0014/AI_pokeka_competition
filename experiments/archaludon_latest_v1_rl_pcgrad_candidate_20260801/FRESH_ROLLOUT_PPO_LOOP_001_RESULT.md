## Interpretation

The engineering milestone is complete: PPO is no longer repeatedly fitting the
same fixed 830 rows. It now collects from the latest checkpoint and updates from
fresh on-policy trajectories while carrying the optimizer state forward.

The 11/16 and 12/16 records are collection observations, not promotion evidence.
They use different seeds and different checkpoints. In particular, the second
batch was 0/2 against historical Silver, so aggregate wins must not hide the
primary-anchor weakness. Before treating the current checkpoint as stronger,
the next step is a checked same-seed, both-seat comparison against its immediate
predecessor and the rule-based Archaludon anchor.
