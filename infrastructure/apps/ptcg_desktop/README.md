# PTCG Human Client

Windows 11 上で、人間が自分で管理する Kaggle 互換ローカルエージェントと対戦する PySide6 / Qt Quick クライアントです。

ルートに `main.py`、`deck.csv`、`cg/` を持つ `.tar.gz` または展開フォルダーを取り込めます。

圧縮ファイルは「tar.gzファイル…」、展開済みの実行ルートは「展開済みフォルダー…」から選択します。

## 対戦画面

対戦画面は Kaggle の人間用対戦ビューワーに近い緑色の盤面を採用し、常時表示されていた診断情報欄を除きました。

カードへカーソルを合わせると、右側の**カードプレビュー**へ日本語版の大きな画像を表示します。

ポケモンには現在 HP と最大 HP の数値、残量バー、ついているエネルギー枚数、ポケモンのどうぐを重ねて表示します。

両プレイヤーのトラッシュは盤面右側にまとめ、カーソルを合わせるかクリックすると全カードを確認できます。

AI の行動後は既定で 1,000 ms 待機し、直前の行動を日本語の文章で表示します。

合法手のカード名とワザ名は日本語カタログで変換し、翻訳が存在しない項目だけエンジンの名称を表示します。

サイド取得は `サイド1`、`サイド2` の形式で表示します。

合法手の番号は盤面カードの左上にも表示し、選択したカードは金色の枠と半透明色で示します。

エネルギー付与は「つけるカード → ポケモン」と表示し、カード効果による二段階選択では現在の段階を画面に示します。

対戦終了時は、アプリ用の改ざん検査付き `.ptcgmatch` に加えて、`cg.visualize_data()` 互換の `.visualizer.json` を同じフォルダーへ保存します。

結果画面からJSONファイル、保存フォルダー、外部の公式ビューワーへ渡す補助ページを開けます。

公式ビューワー用JSONには双方の手札、山札順、サイド内容が含まれるため、補助ページは注意を表示し、利用者が確認ボタンを押すまで外部へ送信しません。

選択したパッケージはファイルごとの SHA-256 で登録し、対戦前のステージングとワーカー内で同じ内容か再検査します。

保存済み submission 55155015 と完全一致する場合だけ `Verified Submission` と表示し、それ以外は `自己管理ローカルエージェント` と表示します。

ローカルエージェントの Python コードとネイティブ DLL は、利用者と同じ Windows 権限で動作します。

子プロセスと Job Object は障害時の終了管理に使いますが、OS のセキュリティサンドボックスではありません。

エージェント、カード画像、人間用デッキは本アプリに同梱しません。

実行手順、JSON履歴の開き方、保存先は `docs/windows_runbook.md` を参照してください。
